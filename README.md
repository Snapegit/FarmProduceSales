

## 🌟 项目简介

这是一个基于 **ASP.NET Core + Vue + MySQL** 构建的完整助农销售系统，功能持续优化中...

### 🧩 功能模块一览

- 用户登录
- 用户注册
- 商品信息
- 商品分类管理
- 商品信息评论
- 商家管理
- 商品订单
- 购物车管理
- 收货地址管理
- 我的收藏管理
- 用户个人中心
- 修改密码
- 找回密码
- 系统用户管理
- 系统配置管理

## ⚙️ 运行环境与工具要求

为了确保项目顺利运行，请确认您的开发环境满足以下条件：

### ✅ 推荐配置
- **.NET Core**: 2.1 及以上  
- **MySQL**: 8.0.41  
- **Node.js**: 16.20.2


⚠️ *温馨提示：版本不一致可能导致依赖冲突或启动失败。*

### 🛠️ 开发工具推荐
- **后端开发**: Visual Studio 2019/2022  
- **前端开发**: VS Code  
- **数据库管理**: Navicat / DBeaver / MySQL Workbench  ...
